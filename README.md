# Panel Vinted

Panel local para seguir el calentamiento de una cuenta de Vinted durante 31 días.

- `panel/index.html`: interfaz (Hoy, Roadmap, Plan, Cuenta, Artículos, Registro).
- `panel/data.js`: datos (plan, artículos, actividad, valoraciones).
- `serve.js`: servidor estático local en el puerto 8765 (`node serve.js`).
- `*.csv`: hojas de seguimiento.

Uso: `node serve.js` y abrir http://localhost:8765
